# MedDev-Project-Starter

Lightweight project initialization and documentation templates for medical device R&D teams.

> Current version: **v0.1.0**

## Overview

MedDev-Project-Starter helps medical device R&D teams start projects with a consistent folder structure and practical documentation templates. It combines a small Python command-line tool with a repository-level multi-project workspace.

The project is intentionally simple: it uses Python's standard library, does not require a database or web service, and is suitable for Windows-based workflows.

## Features

- Create a new project folder from the command line.
- Support Chinese and English project names and Windows paths.
- Generate eight standard R&D folders and a project-specific `README.md`.
- Refuse empty or invalid Windows folder names.
- Avoid overwriting an existing project folder.
- Provide a multi-project workspace under `Projects/`.
- Provide reusable templates for project, testing, technical analysis, and risk analysis documents.
- Keep AI-assisted analysis traceable and subject to human review.

## Project Structure

The repository currently contains the following top-level areas:

```text
MedDev-Project-Starter/
├─ meddev_starter.py              # Command-line project initializer
├─ Projects/                      # Multi-project R&D workspace

│  ├─ 测试报告模板.md
│  ├─ 技术分析模板.md
│  └─ 风险分析模板.md
├─ 00_Project_Management/         # Repository-level project management
├─ 01_需求输入/
├─ 02_法规标准/
├─ 03_设计开发/
├─ 04_测试验证/
├─ 05_AI分析记录/
├─ 06_输出文件/
├─ 07_历史版本/
├─ .github/                       # Issue and pull request templates
├─ CONTRIBUTING.md
├─ CHANGELOG.md
├─ CODE_OF_CONDUCT.md
├─ LICENSE
└─ README.md
```

Each project under `Projects/` contains these six working areas:

```text
01_需求输入/
02_法规标准/
03_设计开发/
04_测试验证/
05_AI分析记录/
06_输出文件/
```

The repository-level folders are documentation-management areas for the template repository itself. They are separate from the folders generated by the Python script.

## Requirements

- Windows 11 or a compatible Windows environment
- Python 3.10 or later
- No third-party Python packages

## Quick Start

Open PowerShell in the directory where you want to create a project, then run:

```powershell
python meddev_starter.py
```

If your Windows installation uses the Python Launcher, use:

```powershell
py meddev_starter.py
```

The script asks for a project name and creates the project folder in the current working directory. It does not modify the repository's existing files.

## Usage Example

Run the program and enter:

```text
胃肠道发光定位装置
```

The script creates:

```text
胃肠道发光定位装置/
├─ 01_项目立项/
├─ 02_设计输入/
├─ 03_技术资料/
├─ 04_设计开发/
├─ 05_测试验证/
├─ 06_供应商资料/
├─ 07_AI分析/
├─ 08_项目记录/
└─ README.md
```

The generated README records the project name, creation time, folder descriptions, and an automatic-generation note. If the entered name is empty, invalid, or already exists, the script reports the issue and does not overwrite existing content.

For a new managed project in the repository workspace, create a folder under `Projects/`, add the six project areas shown above, and use the files in `Templates/` as references.
