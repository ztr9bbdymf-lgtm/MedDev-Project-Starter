# MedDev-Project-Starter

MedDev-Project-Starter 是一个面向医疗器械研发人员的轻量级项目初始化工具，通过命令行快速创建统一的项目资料目录。

## 当前版本

v0.1

## 项目定位

本项目是一个面向医疗器械研发人员的轻量级项目初始化工具，用于快速建立研发项目的基础目录和文档管理结构。它适合用于 POC 创新项目、医疗器械结构设计、工程验证和注册资料准备等场景。

## 文件结构说明

仓库根目录包含初始化程序和项目说明；运行程序后，可按以下目录管理研发资料：

```text
00_Project_Management/  项目计划、会议和进度管理
01_需求输入/            产品、临床和用户需求
02_法规标准/            法规、标准和适用性分析
03_设计开发/            设计方案、图纸和开发资料
04_测试验证/            测试、验证和确认资料
05_AI分析记录/          AI 辅助分析及人工复核记录
06_输出文件/            报告、演示文稿和正式输出
07_历史版本/            历史版本及归档资料
```

每个目录中的 `README.md` 都说明了该目录的用途和建议存放的文件类型。

## 使用流程

1. 运行 `meddev_starter.py`，输入项目名称并创建项目基础目录。
2. 在 `00_Project_Management` 中建立项目计划、任务和会议记录。
3. 按研发流程将需求、法规标准、设计开发和测试验证资料放入对应目录。
4. 将 AI 辅助分析过程和人工复核结果记录在 `05_AI分析记录`。
5. 将阶段性正式成果整理到 `06_输出文件`。
6. 旧版资料移动到 `07_历史版本`，并保留清晰的版本说明。

## 项目库说明

`Projects` 是多项目研发项目库。当前已建立以下项目目录：

- `POC_胃肠道发光定位装置`
- `POC_LED发光定位夹`
- `一次性冲洗吸引器`
- `无针雾化导药仪`

每个项目使用相同的六阶段结构，便于团队统一归档、查找和比较不同项目的研发资料。项目专属文件应放入对应项目目录，不同项目之间不要混放资料。

## 如何创建新研发项目

1. 在 `Projects` 下新建一个以项目名称命名的文件夹。
2. 在项目文件夹内创建 `01_需求输入`、`02_法规标准`、`03_设计开发`、`04_测试验证`、`05_AI分析记录` 和 `06_输出文件`。
3. 参考 `Templates/项目模板说明.md`，将需求、法规、设计、验证和输出资料归档到对应目录。
4. 对测试报告、技术分析和风险分析，可直接参考 `Templates` 中的模板。
5. 项目结束或版本更新时，将旧版资料按版本说明归档，避免直接覆盖重要文件。

## AI辅助研发流程

1. 明确研发问题，并收集需求、法规标准、技术资料或测试数据。
2. 使用 AI 辅助进行资料整理、技术分析、方案比较或文献摘要。
3. 将 AI 使用过程、输入资料、输出结果和人工判断记录在项目的 `05_AI分析记录`。
4. 由研发人员核对事实、法规依据、计算结果和安全相关结论。
5. 对需要确认的内容安排实验、测试或专家评审，并将证据归档到对应项目目录。
6. 只有经过人工复核和必要验证的内容，才可整理到 `06_输出文件`。

AI 输出不能替代法规判断、设计评审、测试验证或最终责任人的专业决策。

## 主要功能

- 输入项目名称并创建同名项目文件夹。
- 自动创建 8 个研发资料目录和项目 `README.md`。
- 空名称、非法名称或同名文件夹存在时，不创建、不覆盖已有内容。

## 环境要求

- Windows 11
- Python 3.10 或更高版本
- 仅使用 Python 标准库，无需额外依赖

## 使用方法

在希望生成项目文件夹的目录中打开 PowerShell，运行：

```powershell
python meddev_starter.py
```

然后输入项目名称并按回车。例如输入 `胃肠道发光定位装置`。

## 自动生成的目录结构

```text
项目名称/
├─ 01_项目立项/
├─ 02_设计输入/
├─ 03_技术资料/
├─ 04_设计开发/
├─ 05_测试验证/
├─ 06_供应商资料/
├─ 07_AI分析/
├─ 08_项目记录/
└─ README.md
```

项目 README 包含项目名称、创建时间、目录说明，以及“本目录由 MedDev-Project-Starter 自动生成”的说明。

## 注意事项

- 项目名称不能为空，且不能包含 Windows 文件夹名称不允许的字符。
- 同名文件夹已存在时，程序会提示并停止，不会覆盖原有内容。
- 本工具只创建基础目录，不替代项目管理、设计开发或法规判断流程。
